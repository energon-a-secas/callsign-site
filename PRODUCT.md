# Callsign: product one-pager

**What it is:** Generate AC6-style codenames for projects and tools

**Who it is for:** A developer who names a lot of repos, services and side
projects, plays Armored Core VI, and wants a naming scheme with rules instead of
another `billing-service-v2`. Projects get a 3-letter acronym they can say out
loud; the tools around them get weapon names from the same fiction.

**Register:** product (a tool someone uses), not brand (a page someone visits).

**The scene:** At the desk in the evening, a new repo half-created in the
terminal on one screen and Callsign on the other, picking the name in under a
minute before running `gh repo create`.

**What done looks like:** A name they would actually put on a repo: a
designation and an acronym copied in one click, or a whole system named as one
build and exported as a Markdown table into its README.
